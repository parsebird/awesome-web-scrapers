## Contributing

Contributions are welcome! This list aims to be a comprehensive, community-maintained resource for web scraping tools across all platforms.

### How to contribute

1. Fork this repository
2. Add your tool to the appropriate category in `README.md`
3. Follow the format: `[Tool Name](url) - Brief description. \`pricing-model\``
4. Submit a pull request

### Guidelines

- The tool should be actively maintained and publicly available
- One tool per line, with a concise description of what it does
- Include the pricing model as an inline code tag (e.g. `free`, `freemium`, `pay-per-event`, `subscription`)
- Add new categories if an existing one doesn't fit — just update the Table of Contents too
- Self-submissions are welcome as long as the tool is genuinely useful
- No affiliate links in community submissions (maintainers may include their own)

### What belongs here

- Cloud scrapers and actors (Apify, Bright Data, Oxylabs, etc.)
- Open-source scraping frameworks and libraries
- Browser extensions for data extraction
- APIs that wrap scraping functionality
- Data cleaning and transformation tools used in scraping pipelines
